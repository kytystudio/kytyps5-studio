# KytyPS5 Studio: legal notes

KytyPS5 Studio is an independent, free launcher and manager for emulator builds of the KytyPS5 family.

## What this project contains
- Its own source code (`studio.py`, `ui/`, build scripts).
- Avatars, sounds and an animated background that are **generated by the program itself**.
  No Sony artwork, logos, fonts, sound effects or other third-party media are included.
- **One third-party image: the KytyPS5 logo** (the winking cat-shaped gamepad, `ui/logo.svg` and the application icon).
  It is the artwork shown by the KytyPS5 launcher, which is distributed under GPL-2.0, and its copyright belongs to
  the KytyPS5 authors. The licence of the artwork itself is not stated separately. It is used here only to
  identify the emulator this tool manages. **Ask the KytyPS5 authors for permission before you distribute
  Studio**, or replace `ui/logo.svg` and `icon.ico` with your own artwork. Using it does not mean the authors endorse this tool.
- Third-party libraries (Python runtime, pywebview, pythonnet and their dependencies) under their own
  licenses; the texts are in `THIRD_PARTY_LICENSES.txt`.

## What this project does NOT contain
- No games, no console firmware or system software, no encryption keys, no dumps of any kind, and no way to download them.
- No emulator builds (forks). Studio downloads them, on request, from the authors' own GitHub releases.
- No game patches and no lists of forks or patches. The only default is the **address** of a metadata-only catalog
  repository (`kytystudio/kytyps5-studio-catalog`), read from `raw.githubusercontent.com` when the user opens
  Settings > Community; it can be changed or emptied there. Nothing from it is installed until the user presses Install.
- No telemetry. The only network traffic is to `api.github.com`, GitHub release downloads and the catalog address above.

  without its author's permission.

## Before you publish the source
- Do not commit `data/` (it holds your saves, trophies, downloaded forks, logs and settings). A `.gitignore` is provided.
- Do not add patch files to `community-catalog/patches/` unless their authors allow redistribution.
- Choose a license for your own code (none is set here, which by default means all rights reserved).
